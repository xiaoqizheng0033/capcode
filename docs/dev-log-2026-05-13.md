## 上半场

### 1. 主页一键展开/折叠所有分类分组

**改动**：`CategoryGroup.jsx` 新增 `forceOpen` prop，`Dashboard.jsx` 工具栏增加切换按钮。

**经验**：
- `forceOpen` 判断用 `typeof forceOpen === 'boolean'` 而非 `forceOpen !== undefined`。JSX 中 `forceOpen={null}` 时 `null !== undefined` 为 `true`，导致 `isOpen = null`（falsy），所有分组永远折叠无法点击展开。
- 按钮合并为一个，在"全部展开/全部折叠"之间切换。

## Bug 调试经验

### `forceOpen={null}` 导致分组无法展开
- 根因：`null !== undefined` 为 `true`，`isOpen = null` → falsy
- 修复：`typeof forceOpen === 'boolean'`

### 内网穿透远程无法点击分组
- 实际原因同上 `forceOpen` bug，与环境无关
- 教训：先排除代码 bug 再怀疑环境

### `git describe` 无 tag 时控制台刷屏
- 根因：`execSync` 默认 stdio 继承父进程，Git fatal 输出到控制台
- 修复：`stdio: 'pipe'` 静默

### Release 接口阻塞页面渲染
- 根因：`Promise.all` 中 release API 调用 GitHub 可能耗时 1-2s
- 修复：release 改为独立异步，页面先渲染

### 侧边栏视觉割裂
- 根因：侧边栏 `bg-white` + 主内容 `bg-gray-50`，中间有间隙
- 修复：统一背景色，去除间隙，主内容去掉 `max-w-5xl` 居中

### 13. `vite build` 路径导致的幽灵旧版

**现象**：修改"作者" → "开发者"后构建，刷新页面仍显示"作者"。

**排查**：
- 后端 API 返回数据有 `author` 字段 → 排除后端
- `curl` 服务端 HTML 中找不到"开发者" → 排除浏览器缓存
- dist JS 中没有"开发者"字符串 → 构建产物是旧的
- dist 文件时间戳 10:27，早于最后改动
- 某次 `vite build` 在错误目录执行（不在 `client/` 下），没有覆盖 `client/dist/`

**根因**：`npx vite build` 在项目根目录执行时，Vite 在当前目录找 `index.html`，找不到就报错退出。dist 没更新，但上一次成功构建的旧产物还在。

**教训**：`vite build` 必须在 `client/` 目录下执行。构建后验证 dist JS 中是否包含新改文字，避免"构建成功但页面没变"的幽灵现象。

## Bug 补充经验

### `node --watch` 不自动重启

### `const` 在 useMemo 前引用导致 TDZ 错误

- **现象**：页面空白，控制台 `Cannot access 're' before initialization`
- **根因**：`todayDate = new Date().toISOString()` 定义在 `useMemo(() => {...todayDate...})` 之后，`const` 存在暂时性死区（TDZ）
- **修复**：`todayDate` 移到所有依赖它的 `useMemo` 之前定义
- **教训**：JS 中 `const`/`let` 有 TDZ，被 `useMemo` 闭包捕获时必须先声明

### 后端 restarted 但 dist 是旧版 → 页面白屏

- 改前端代码后 `vite build` → 修复 bug 再次构建 → 重启后端
- 如果后端启动时加载的是第一次构建的旧 dist（因文件缓存或路径问题），前端报错
- **快速验证**：`curl http://localhost:3456/` 看 HTML 引用的 JS 文件名是否最新
- **教训**：前后端分离时，确保构建完成、文件时间戳已更新后再重启后端

### 24. 右侧面板拖拽失效

**现象**：右侧拖拽一次后失效

**根因**：`useResizable` 使用 `clientX` 绝对坐标，右侧面板位置偏右，`clientX` 不能直接作为宽度。且拖拽条在 `showRightPanel` 条件渲染内，状态切换导致 hook 重置。

**修复**：改为 delta 驱动（`startRef` 记录起始位置和宽度，每次 `mousemove` 计算差值）。左右面板用 `side` 参数区分拖拽方向。

### 25. AI 生成卡片只出标题

**现象**：`noteToCard` 调用后卡片只有标题，正面/背面为空

**排查**：
- 后端 `extractOnly` 路径中，`cardFront`/`cardBack` 正确赋值，`res.json({title,front,back})` 返回正确
- 前端旧代码用 `data.content?.front` 但 `data.content` 此时是 undefined（`extractOnly` 返回的是 `{title,front,back,tags}` 而非 `{content}`）
- `GET /cards` 返回的 `content` 是 JSON 字符串，前端 `card.content?.front` 取不到对象属性

**修复**：
- 前端 `noteToCard` 改为 `setQuickCard({ title: data.title, front: data.front, back: data.back })`
- 后端 `GET /cards` 返回时 `JSON.parse(content)` 转为对象

### Bug 经验

- `git describe --tags --abbrev=0 HEAD` 只返回当前 HEAD 可到达的 tag → 对多分支项目或 HEAD 在旧 commit 上的情况，返回的是旧 tag 而非项目最新 release
- 改用 `git tag --sort=-taggerdate | head -1` 获取本地所有分支中 tagger 日期最新的 tag
- 典型场景：openclaw 项目 HEAD 在旧版本，`git describe` 返回 `v2026.4.19-beta.2`，但最新 release 是 `v2026.5.16-beta.1`
